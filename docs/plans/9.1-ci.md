# Plan — 9.1 CI (GitHub Actions)

Status: **shipped** (config committed; first run proves it on GitHub) · Roadmap 9.1 · Effort: S

## Goal

Run the full test suite automatically on every push and PR so the guardrails
this repo relies on — the byte-identical `tree.json` baseline, the 95% fidelity
gate, 120 unit + 11 e2e tests, and the mock-Figma runs — are enforced by CI,
not by remembering to run `npm test`.

## Design

`.github/workflows/ci.yml`:

- **Triggers**: `push` and `pull_request` (all branches, so this feature branch
  is covered too).
- **Runner**: `ubuntu-latest`.
- **Node**: **24** (newest LTS), per decision. (`package.json` engines is
  `>=18`; local dev/this environment is 22 — CI on 24 also catches
  newest-LTS drift.)
- **Steps**:
  1. `actions/checkout@v4`
  2. `actions/setup-node@v4` with `node-version: 24` and `cache: npm`
  3. `npm ci` (lockfile present)
  4. `npx playwright install --with-deps chromium` — the e2e + fidelity
     harness launch real headless Chromium
  5. `npm test`

## Notes / caveats

- Browser-driven suite → the Chromium install step is required; without it the
  e2e/preview tests can't launch. Runtime ≈ a couple of minutes.
- Unlike the mapping items, this can't be proven by the preview/baseline
  machinery — its real verification is the **first CI run on GitHub**.
- Requiring green-before-merge is a GitHub branch-protection *setting* (not repo
  code); out of scope for this file.
