# Plan — 1.4 clip-path

Status: **shipped** (circle→radius; rest rasterized; 100% preview fidelity) · Roadmap 1.4 · Effort: M (scoped)

## Problem

`clip-path` (circular avatars, angled section dividers, polygon crops) is
ignored today — the element renders as its full unclipped box.

## Does this need Figma? Mostly no.

Two honest outcomes, both verifiable without live Figma:
- **circular crop on a square element** → Figma corner radius (border-radius
  50%). Editable, exact, preview-verifiable via SVG.
- **everything else** (polygon, path, non-square circle, ellipse, inset, `url()`
  masks) → route through the existing **2.2 rasterize fallback**: a
  pixel-perfect element screenshot. Guarantees 1:1 for angled dividers etc.
  without building unverifiable Figma vector-mask nodes.

Full Figma vector masks (`node.isMask`) are deferred — they can't be verified
without Figma and the raster fallback already yields 1:1 output.

## Design

Pure `mapClipPath(clipPath, rect)` in css-map → one of:
- `null` for `none`
- `{ kind: 'radius', radius: {tl,tr,br,bl} }` for `circle(...)` on a (near-)
  square element (radius = min(w,h)/2)
- `{ kind: 'raster' }` for every other non-none clip-path

Consumers:
- `mapBoxStyle`: when `kind==='radius'`, set `style.radius` (+ `clip`).
- `rasterReason` (extractor): when `kind==='raster'`, return `'clip-path'` so
  the element is screenshot-rasterized. Pass the element rect in.
- `rasterizeFlagged`: add `omitBackground: true` to the element screenshot so
  clipped-away areas are transparent (correct compositing in Figma), not the
  page background.

Baseline-safe: `clip-path: none` (default) → `null`, no change. Pricing-card has
no clip-path.

## Test plan (TDD)

1. Unit (`clip-path.test.js`): `mapClipPath` — none→null; circle on 40×40 →
   radius 20 ×4; circle on 80×40 → raster; polygon/inset → raster.
2. Baseline: pricing-card `tree.json` byte-identical.
3. e2e: a square avatar `clip-path: circle(50%)` → node has full corner radius,
   not rasterized; an angled `polygon(...)` divider → `[raster]` node with bytes.
4. Preview: circular-crop fixture overlay (radius) matches; record fidelity.

## Risk / rollback

Additive; non-clip elements unchanged. The raster path reuses shipped 2.2
machinery. One commit.
